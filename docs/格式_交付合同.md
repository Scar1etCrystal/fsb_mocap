# 格式：R1 交付合同（PoseCapture 插件 / MoCap Doctor 消费的 take 目录）

> 依据：需求文档 §2 + 消费端代码（`gvhmr_pose_capture.py` `import_pose_to_blender`、`hand_body_merge.py`、
> MoCap Doctor `pkl_hand.py`）+ 两段参考素材逐字段核对（`python -m fsb.contract <take>` 两段都 OK）。

## 目录

```
<take>/
├ gvhmr/hmr4d_results.pt_person-0.pkl   身体：smpl_params_global / smpl_params_incam
├ gvhmr/0_input_video.mp4               （参考素材有；插件"重新生成"时用，可选）
├ hamer/<名>_hamer_data.pkl              手部原始（MANO 布局）
├ hamer/merged.pkl                      身体 + 手（插件优先读它）
└ <take>.pkl                            merged 的副本（参考素材逐字节相同；MoCap Doctor 取根目录第一个 *.pkl）
```

## 坐标系 / 单位 / 帧

| 项 | 约定（实测） |
|---|---|
| 世界系（global 分支） | Y 朝上（重力反向）；Z = 首帧相机视线的水平投影（人面朝相机 ≈ −Z）；X = Y×Z；**首帧 transl 的 XZ = 0**；单位米 |
| 与相机系的关系 | 水平静止相机：世界 = RZ180·相机（OpenCV：x 右 y 下 z 前），RZ180 = diag(−1,−1,1)。`hand_body_merge.py` 对 HaMeR 朝向做的就是这个补偿 |
| incam 分支 | 参考素材里与 global **逐位相同**（插件 INCAM/BOTH 模式只从 incam 取 body_pose 和手，根朝向、位移永远取 global） |
| 旋转 | 轴角 float32；body_pose = SMPL-X 21 关节 × 3（关节 1..21，手腕 = 19/20 → 列 57:63）；手 = MANO 15 关节 × 3 |
| betas | (F,10) float32，参考素材全片恒定 |
| 帧 | 数据下标 0..F−1 → Blender 帧 1..F；F = 身体帧数；手部可能多 1 帧（1499 段：1500），合并时按身体裁齐 |
| 根高度 | transl.y 绝对值无硬约定（参考 1.24–1.67），插件减 `high_from_floor`，MoCap Doctor 向导再落地 |

## 文件字段

**person pkl**（pickle 协议 5）：两分支各 `body_pose (F,63)`、`global_orient (F,3)`、`transl (F,3)`、`betas (F,10)`，全 float32。

**hamer_data pkl**（默认协议）：

| 键 | 形状 / 类型 | 语义 |
|---|---|---|
| global_orient | (F,2,3,3) f32 | [0]=左手（**镜像成右手的表示**，真左手 = M·R·M，M=diag(−1,1,1)），[1]=右手；未检测 = 全零 |
| hand_pose | (F,2,15,3,3) f32 | 手指局部旋转矩阵（左手同样是镜像表示） |
| global_orient_valid | (F,2) uint8 | |
| hand_pose_abs_flat | (F,2,15,3,3) f32 | 参考素材全零（未使用） |
| global_orient_abs_lr | (F,2,3,3) f32 | [0]=M·global_orient[0]·M（真左手），[1]=global_orient[1] |
| hand_keypoint_conf | (F,2) f32 | 可选（999v2 有、1499 无） |

**merged pkl**（协议 5）：两分支各 = 身体 4 字段 + `left/right_hand_pose (F,45)`（**真左手表示**，插件直接当骨旋转，
不加 MANO 均值手）+ `left/right_hand_global_orient (F,3)`（= 轴角(RZ180·原始朝向)，插件不用，MoCap Doctor 只取帧间差）
+ `left/right_hand_is_detected (F,) bool` + 可选 `*_keypoint_conf (F,)`；
`hamer_merge_info = {source, method='build_hand_pose_arrays', wrist_mode='stitch', reference_branch='incam',
mirror_left_hand=True, gvhmr_frames=F, hamer_frames_original, merged_frames=F}`。
**method 必须是 build_hand_pose_arrays（或 mano2smplx）**：插件据此认定左手已镜像、不再二次翻转。

merged 的 body_pose 只在手腕两关节（19/20）与 person pkl 不同（合并时写入手腕），其余逐位相同。

## 新链路怎么满足（fsb.package）

- 身体：SMPL-X 转换输出 → 世界系（fsb.world）→ global；incam 默认 = global 副本（与参考一致）。
- 手：SMPL-X 转换输出的 left/right_hand_pose 直接写 merged；手部原始 pkl 由正运动学反推：
  raw = RZ180·G_wrist（左手 RZ180·M·G·M），使插件"重新合并"得到与 body_pose 相同的手腕（往返误差 2e-6°）。
- 性别前缀不在 pkl 里：插件导入时选 FEMALE → 源骨架 `f_avg_*`（两段素材都是 f_avg），remap 表才对得上。
