# 方案：MHR → SMPL-X 关节集的骨骼级重定向（替代网格拟合）

## 为什么

- Fast SAM 3D Body 的提速一半来自把**迭代式 MHR→SMPL 网格拟合**换成前馈网络（快 1 万倍）；官方 MHR→SMPL-X
  路线就是那个迭代拟合，走它会把瓶颈加回来。
- PoseCapture 插件只读 SMPL-X 关节集上的逐帧**局部旋转**（身体 21 + 手 2×15）+ 根位移，骨架用自带 SMPLX_FEMALE
  模板搭，**不读 betas**（导入函数里一次都没引用）。所以不需要 SMPL-X 网格，只要关节旋转对。
- 作者自带的前馈映射只出 SMPL 身体（无手指），且与 SAM3D 自己的骨架差 7–27°（脚 15–27°，见下）。

## 做法（fsb/retarget.py）

SAM3D 每帧给出 MHR 127 关节的全局旋转与位置（用最终参数重算，见原始输出格式文档）。SMPL-X 55 关节 ← MHR：

| SMPL-X | MHR | 标定 |
|---|---|---|
| Pelvis / Spine1–3 / Neck / Head / Collar | root / c_spine1–3 / c_neck / c_head / clavicle | 零位对零位（两边零位都是直立中性；SMPL-X 脊柱各节很短、连线是折线，按骨向对齐会拧出 61°） |
| Hip / Knee | upleg / lowleg | 骨向对齐 + 逐帧按 MHR 位置摆动校正 |
| Ankle | 旋转取 transversetarsal，骨向 = talocrural→ball | 同上（脚的俯仰/偏航与 MHR 完全一致） |
| Foot（脚尖） | ball | 零位对零位（两边零位脚尖都水平朝前） |
| Shoulder / Elbow | uparm / lowarm | 骨向对齐（补 MHR 零位 A 姿态 ↔ SMPL-X T 姿态）+ 摆动校正 |
| Wrist | wrist | 腕→中指根 + 小指根→食指根 成架（掌面朝向） |
| 手指 1/2/3 | index/middle/ring/pinky 1–3；拇指 1–3 ← thumb1–3（thumb0 是腕骨辅助节） | 骨向对齐 + 摆动校正（末节用 MHR null 关节） |

每帧：`G_j = R_mhr(t)·R0⁻¹·A_j`（R0 = MHR 零位旋转，A_j = 标定），肢体再按位置摆动校正；局部 `L_j = G_parent⁻¹·G_j`。

## 验证（两段素材）

| 项 | 结果 |
|---|---|
| 可对应的 46 根骨指向 vs MHR 关节位置 | ≤ 0.04°（随机姿态 ≤ 0.0001°） |
| 躯干在 MHR 零位上的局部旋转 | 0.00° |
| 相机系骨盆投影 vs YOLO 两髋中点 | 中位 13 px |
| 网格并排渲染（MHR vs 重定向 SMPL-X） | 指向手势、托腮、举手、手指、腿脚一致（reports/render/t999_f*.png） |
| 作者前馈 MHR→SMPL 的骨向 vs MHR | 大腿 12–22°、小腿 7–10°、**脚 15–27°**、上臂 15–22°、前臂 22–28°（中位） |

结论：骨骼重定向原样传递 SAM3D 的估计（尤其脚和手指）；作者的前馈映射近似误差偏大，只作交叉验证。
