# 云端运行手册（FastSAM3DBody → 合同目录）

## 环境（AutoDL，RTX 4080 32 GB，已验证 2026-10-04）

- conda 环境 `/root/autodl-tmp/envs/fast_sam_3d_body`（py3.10.8、torch 2.5.1+cu124），代码 `/root/autodl-tmp/Fast-SAM-3D-Body`
  （commit 见 data/cloud_meta/fsb_commit.txt），我们的代码 `/root/autodl-tmp/fsb_frontend`。
- 三个坑（都已处理）：
  1. DINOv3 主干用 torch.hub 加载，会先连 GitHub 查分支 → 运行前 `source /etc/network_turbo`（学术加速）。
  2. MoGe-2 权重走 HuggingFace → `export HF_ENDPOINT=https://hf-mirror.com`（直连不通）。
  3. MoGe v2 调 `utils3d.pt.*`，PyPI 的 utils3d 0.1.1 没有 → 已升级到 GitHub 版 utils3d 1.7，run_take.py 里把
     `utils3d.pt` 指到 `utils3d.torch`（两个用到的函数都在）。
- 无卡模式下容器内存上限较小，MHR 前向别一次塞 256 个姿态（会被 OOM 杀）。

## 一段视频

```bash
cd /root/autodl-tmp && source /etc/network_turbo && source fsb_frontend/cloud/env.sh && export HF_ENDPOINT=https://hf-mirror.com
python fsb_frontend/cloud/run_take.py --video videos/X.mkv --out fsb_work/X          # 跟踪/选人/抽查图/焦距/推理
python fsb_frontend/cloud/recompute_skel.py fsb_work/X                                # 用最终参数重算骨架（必须）
python fsb_frontend/cloud/mhr2smpl_check.py fsb_work/X                                # 可选：交叉验证
```
然后在本地（或云端）：`fsb.convert.convert_take` → `fsb.package.package_take` → `python -m fsb.contract` → `python -m fsb.compare`。
